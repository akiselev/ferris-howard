# The Effective Calculus: Meta-Axioms for Certified Approximation

**Status:** Draft 0.1 · The program the whole stack has been converging on.
**The idea, stated plainly.** Mathematics' unit of currency is the exact theorem about a small structure. Physics' unit of currency is the *effective equation*: a tractable model standing in for an intractable one, valid in a regime, with an error you're supposed to feel guilty about. The proposal: make the effective equation a first-class formal object — a **certified morphism between models** — and build the trait-hierarchy/Atlas machinery one level up, over *systems and their compressions* instead of over algebraic structures. The deliverable of the whole program is a calculus in which "here is your intractable system; here is a tractable equation for it; here is the theorem bounding how wrong it is, in this regime" is a single machine-checkable artifact — and in which *searching for new effective equations* is a directed Atlas operation rather than a stroke of genius.

## 1. This is not built from nothing: the five pillars that already exist

The idea sounds like science fiction until you audit the literature, at which point it turns out four fields independently built pieces of it without noticing they were building the same thing. **(P1) Rigorous effective-equation derivations.** Mathematical physics has *proven* effective equations with quantitative rates: Gross–Pitaevskii and Hartree dynamics derived from N-body quantum mechanics with explicit error bounds in N (the Erdős–Schlein–Yau lineage and its quantitative successors); Lanford's derivation of Boltzmann from hard spheres; Vlasov and mean-field limits; homogenization theory, which derives effective PDE coefficients for oscillatory media *with corrector estimates* — a whole subfield whose product is literally "certified approximation equation within given bounds." These are existence proofs that the morphisms we want are real mathematical objects. **(P2) Certified model order reduction.** Numerical analysis independently built the engineering wing: reduced-basis methods with *a-posteriori error bounds* — surrogate models that carry certified, cheaply-evaluable error functionals, an established field with "certified" already in its textbooks' titles. Its deep lesson transfers wholesale: for hard systems you rarely get a-priori bounds, but you can get **a-posteriori certificates** — error bounds computed alongside the approximation, monitoring validity as you go. **(P3) Exact projection formalisms.** Mori–Zwanzig says any coarse-graining is *exact* if you keep the memory kernel — locating all approximation error in one nameable object (the discarded memory), which is precisely the structure a formal error-budget wants. **(P4) The renormalization group**, physics' own meta-axiom system: the discovery that flowing to effective descriptions is an *operation on theory space* with fixed points and universality — i.e., that compressions compose and cluster. Universality classes are the physical proof that "grouping systems together" under compression is a natural equivalence. **(P5) Compositional systems theory.** Applied category theory (structured cospans, operads of wiring diagrams, categorical thermodynamics) built the grammar for "systems, subsystems, and couplings" as formal objects — candidate syntax for the SystemClass layer, so far mostly without quantitative error content. The synthesis nobody has done: P5's grammar + P1's theorems + P2's a-posteriori discipline + P3's error localization + P4's structure of theory space, in one proof-carrying framework. That synthesis is this program.

## 2. The formal shape, in FH syntax

```rust
trait SystemClass<Self> {
    // meta-axioms: the properties compressions consume
    dof:       Self -> Nat;                  // degrees of freedom / scale parameter
    locality:  LiebRobinsonData;             // finite information velocity
    symmetry:  SymmetryData;
    // laws: e.g. clustering, entanglement structure (area-law tags), ...
}

// The first-class citizen: a certified approximation.
struct Effective<M1: SystemClass, M2: SystemClass> {
    compress:  M1 -> M2,                     // the map (projection, mean-field, RG step)
    regime:    Prop,                          // the where-clause: scaling limit, coupling window
    error:     ErrorFunctional<M1, M2>,       // a-posteriori preferred; observable-indexed
    cert:      Proof,                         // the theorem: within regime, error bounds hold
}
```

Three structural commitments, each inherited from a pillar. *Errors are observable-indexed* (an effective theory is good **for** something — energies, correlators at scale ℓ, dynamics to time T — never good simpliciter), which is what makes composition honest: `Effective` morphisms compose with error budgets *adding along the pipeline*, giving multi-stage derivations (microscopic → mean-field → hydrodynamic) as audited chains — Round 4's C3 total-error-budget theorem was this calculus's first instance, built by hand. *Regimes are hypotheses, not apologies* — the where-clause is checked, and outside it the artifact says nothing, which is the honesty that distinguishes a certified effective theory from a folk one. *A-posteriori is the default* — the error functional is something you evaluate on the actual trajectory/state, P2's great trick, because for exactly the systems that matter, a-priori bounds are provably out of reach.

### 2.1 The error field

The residual, upgraded from a number to a geography. An **error field** assigns to each point — better, each region — of an indexing domain not a value but a *theorem*: a certified bound on the error there. In dependent type theory the slogan is literal: the field is a dependent function into certified statements, a section of a bundle of theorems,

```rust
struct ErrorField<X: Site, Obs> {
    at:       (U: Region<X>) -> Certified<Bound<Obs, U>>,  // theorem-valued sections
    restrict: (V ⊆ U) -> (at(U) -> at(V)),                  // bounds localize for free
    glue:     Cover<U> -> Certified<Bound<Obs, U>>,          // lax: compose with certified loss
}
```

— which is to say, mathematically, a **(lax) sheaf of certified bounds**: theorems restrict to subregions exactly, and glue across covers with an explicit certified cost (triangle inequalities are the gluing maps). The domain `X` is deliberately any site, and the generality is the point: physical space (§8.1's residual cartography *is* an error field over the solar system), the mode/subspace lattice of a Hilbert space (the couette-re-e tail lemma *is* an error field over frequency space — one theorem on the low modes, another on the tail), time (the certified TDVP monitor *is* an error field along a trajectory), parameter space (a regime clause *is* the superlevel set of an error field — regimes are recovered as **contours** of the field, refining the where-clause from a binary hypothesis into a topography of validity), and phase space, where the right vocabulary already exists: the *microlocal* error field, bounding failure jointly in position and frequency — the residual's wavefront set as the certified answer to "where, and at which scales, does this model break," which is precisely what §8.1's frequency-fingerprint recognition computes without saying so.

Three consequences make the definition load-bearing rather than decorative. **Composition**: error fields add pointwise along `Effective` composition, so multi-stage derivations carry a composed field, not just a composed scalar — the error budget becomes a budget *map*. **Resolution as field decomposition**: `atlas resolve` rewrites cleanly at field level — attribution decomposes one field into a sum of source-labeled component fields (the cartography), recognition matches a component's shape, promotion lifts a coherent component field into the model, and the certified floor ε_noise + ε_chaos + ε_unattributed is a field decomposition with the unattributed component's *support* exhibited. **Retroactive unification, which is the §7 justification**: tail lemmas, trajectory monitors, regime clauses, residual cartography, and numerical analysis' per-element a-posteriori indicators (the DWR method's local contributions — error fields avant la lettre, floating-point edition) are all instances of one type — five existing constructs compressed into one definition, the discovered-stratum acceptance test passed by the ontology's own newest member, on arrival. Honest note on status: the error field is derived, not primitive — Props, bounds, and sites already suffice to build it — but it is *named* because a half-dozen operations produce or consume one, and per the project's oldest criterion, a definition is API design judged by downstream reuse.

## 3. The Atlas, one level up


Every Atlas operation lifts. The **skeleton index over derivations**: anti-unify the known proofs in P1 — GP, Hartree, Vlasov, homogenization — and extract the shared derivation skeleton (a scale separation consumed, a fluctuation bounded, a Grönwall closure); the meta-dictionary's rows are now *whole derivations*, and `similar` answers "which known compression is this system shaped for?" **`atlas home` becomes regime-finding**: the true home of an effective equation is the weakest meta-axioms under which its error theorem survives — computed, not folklore, and directly answering "how far can I trust mean-field here?" **`transport` becomes compression transfer**: apply a derivation skeleton to a system class it's never met, dispatch the resulting candidate effective equation to falsification (numerics against the error claim) or proof — the mechanized version of how hydrodynamics colonized electron flow and cold atoms. **B1's abstraction synthesis gets its hardest benchmark**: delete "mean-field limit" as a concept, hand the system the GP and Vlasov derivations, and require it to re-invent the notion — the deletion methodology, one level up. And a new operation earns its name: **`atlas envelope <system> <observables> <budget>`** — given an intractable system, search the meta-dictionary for the composition of certified compressions reaching a tractable model within the error budget, returning the effective equation *with its pedigree*. That operation is the program's product.

## 4. The flagship application: large entangled systems

The target named in the prompt, and the right one. For quantum many-body dynamics the tractable manifolds exist (MPS/tensor networks, Gaussian states, cluster expansions) and the projection principle exists (Dirac–Frenkel/TDVP), but the *certified error* layer is thin: a-posteriori error bounds for time-dependent variational dynamics are a young, small literature — genuinely open research sitting exactly at this program's origin. Concrete ladder: (i) formalize the TDVP projection-error identity (the local error is the norm of the projected-out residual — computable on the fly, Mori–Zwanzig's lesson in miniature) and ship the **certified error monitor for tensor-network dynamics**: every MPS simulation gains a running theorem "the true state is within ε(t) of this manifold trajectory, given monitored residuals" — the fluid track's blowup detector, transplanted to entanglement, and the single highest-leverage artifact in the program because every quantum-simulation group on earth runs the uncertified version daily; (ii) certified adiabatic/quasi-locality compressions (Lieb–Robinson-based truncation theorems — P1-grade results that exist and want formalizing) as the first library of `Effective` morphisms; (iii) the `envelope` operation running over that library against named intractables — spin liquids, FeMoco-class molecules (quantum chemistry Tier 4's wall, by design), Hubbard-adjacent dynamics — producing effective equations with pedigrees where currently there are ansätze with reputations.

## 5. The no-free-lunch layer, load-bearing as always

The program needs its own no-gos, and complexity theory supplies their shape: QMA-hardness and undecidability results already imply that certified compression *cannot* be universal — there exist system classes where no polynomial-size effective description with checkable error can exist (else hard problems collapse). Making that precise — **the compressibility phase diagram**: which meta-axiom sets (locality + gap + area law + ...) *entail* certified-approximability, and which provably forbid it — is B6's decidability cartography lifted one level, and it is not overhead but half the science: the boundary of the compressible is a new physical-mathematical object, and every no-go sharpens the `envelope` search by pruning impossible requests. Honest prior-art note: fragments exist (area laws entail MPS approximability — a *proven* compressibility theorem; hardness results dot the other side); the diagram as an object of systematic study does not.

## 6. The classical flagship: the N-body problem

The program's second flagship, alongside §4's entangled systems — and its founding parable. The N-body problem is "unsolved" in a precise and instructive way: Bruns and Poincaré killed quadrature solutions (no further algebraic first integrals) and Poincaré found chaos, **yet an exact analytical solution exists** — the Sundman–Wang convergent series, valid for all time excluding collisions — and it is computationally void, its convergence too slow to extract a single astronomical prediction. The classical reification was achieved a century ago and bought nothing. Meanwhile everything of *value* ever said about N-body dynamics is an `Effective` morphism avant la lettre: Laplace–Lagrange secular theory (averaging, with a quantitative remainder theorem — the first pedigree-carrying effective equation in physics), Lidov–Kozai reductions, KAM tori (with a mature *a-posteriori* computer-assisted format — P2's discipline already native to the field), Nekhoroshev exponential-time stability bounds ("solutions within bounds where the bounds are theorems," verbatim), validated integration tubes, and shadowing lemmas. Celestial mechanics is the Effective Calculus practiced for two centuries without the type system.

**The flagship artifact:** the certified N-body solution *object* — not a formula but the `envelope` operation's portfolio: given initial data, observables, horizon T, and budget ε, compose from the certified library (validated tubes for short T; averaged secular flows with remainder theorems for long T; Nekhoroshev certificates for exponential T; KAM certificates for infinite-T statements about tori) and return the value with its pedigree. Ladder: **M1** — the zero-error layer: Kepler certified in closed form, Sundman–Wang formalized at statement level as the exhibit anchoring the thesis; **M2** — first morphisms: the quantitative averaging theorem (Laplace–Lagrange with its error bound as the library's founding entry), a validated-integration tube morphism, Lidov–Kozai; **M3** — kernel-check the computer-assisted KAM/Nekhoroshev genre (the a-posteriori KAM literature is built for exactly this promotion) and the proven periodic-orbit corpus (the figure-eight choreography's interval-arithmetic proof, re-checked at kernel strength); **M4** — the grand target: composed certified statements about the *actual solar system* — "no close encounters within T years given ephemeris enclosures," certified secular drift bounds — putting proven floors under what is currently celebrated unverified numerics.

**The design payment this flagship forces.** Sundman–Wang is an `Effective` morphism with error ≡ 0 and cost ≈ ∞, which exposes a missing axis: the type must carry a **cost functional** alongside error and regime. `Effective` becomes an (error, regime, cost) triple, "closed form" is revealed as the zero-error corner of a Pareto surface, and "solution" — the word itself — is redefined as the reachable frontier of that surface for stated observables. The N-body problem doesn't just test the calculus; it completes its type signature.

**On reification.** Can envelope outputs become "regular analytical solutions"? Yes — by the mechanism mathematics has always used: *promotion to a named function with a characterizing theorem*. "The" solution of x″ = −x is called sine; the Painlevé transcendents are reified solution schemes; special functions are, historically, effective calculi that earned names. In dependent type theory the promotion is literal: an envelope output is a term `solve : (ic, obs, T, ε) → (value, proof of |value − truth| ≤ ε)` — a first-class analytical object whose *computation rule is the meta-axioms and whose interface is ordinary mathematics*. Reification and computability stop being in tension: the named object is the theorem-carrying function, the calculus is its evaluator, and Curry–Howard is the reason no information is lost in the collapse.


## 7. The reflexive meta-axiom: discovery as constitution

The calculus's final structural commitment, and the one that makes it a discipline rather than a framework: **most meta-axioms are not legislated — they are computationally discovered**, via the Atlas search process, and the discovery process is itself part of the mathematics. Driving an agent to find a meta-solution is not preparation for the field; it *is* the field's characteristic activity.

Soundness first, because reflexivity invites suspicion. The discovered stratum consists of definitions-with-laws (`class`es), never logical axioms: the kernel, the type theory, and the acceptance semantics are the small fixed undiscovered core, and everything mined above them is a conservative extension. Consistency is therefore never at stake in discovery — only *fruitfulness* is, which converts a foundational hazard into an empirical science with a safety floor. The philosophical lineage is Lakatos (concepts discovered under proof-pressure) and the set theorists' extrinsic justification of large cardinals (axioms adopted for fruitfulness); the novelty is the loop made computational with the kernel as oracle.

The selection principle is compression: the preferred meta-axiom set is the one minimizing the description length of the certified derivation corpus — maximal proof-reuse and envelope reach per definition. Meta-axioms are thereby *effective theories of the corpus itself*, and inherit the calculus's full structure: a **pedigree** (source corpus, deletion benchmarks passed, synthesis trace), a **regime** (discovered axioms are conditional — they hold where they compress, a where-clause classical axioms never carried), and a **deprecation path** (displaced when a better compression is certified; axiom churn, versioned, as normal science).

The practice loop: the envelope operation's **failure log is the research frontier** — a failed compression request localizes a missing meta-axiom, B1-synthesis searches for candidates, and candidates are scored on corpus-compression ratio, transport yield, and regime breadth. Two guardrails keep the empiricism from self-confirmation, both inherited and lifted from the agent layer: **held-out validation** (temporal splits — mined from the old corpus, must pay rent on new derivations; cross-domain splits — discovered in the quantum library, validated in fluids) and the **anti-cheat protocol at the meta level** (nontriviality floors on instance counts and reach, so score cannot be Goodharted by axioms that memorize their training corpus). An accepted meta-axiom enters the lattice carrying all of the above; a rejected one enters the record too, because at this level negative results are cartography.

Terminology, for the record: "metamathematics" belongs to Hilbert and means nearly the opposite (securing foundations from above); this stance is better named **corpus-grounded foundations**, its mined layer the **discovered stratum**, with "meta-axioms" retained as the working term. The reflexive summary: the calculus claims every good description of a complex system is a certified compression with a pedigree and a regime — and then submits to its own claim, deriving its axioms as certified compressions of its own history, under oath like everything else.

## 8. Meta-closed forms: closure as a moving target

The calculus's answer to "what is a solution, finally": redefine closed form inside the ontology. A **meta-closed form** is a triple (F, R, τ): a finite expression F over the current certified basis; a reified residual R — the error, as a first-class object rather than an apology; and a certified refinement operator τ with a contraction certificate — each application provably shrinks R at a proven rate, so "integration over the error" is literal iteration with a convergence theorem. The object is *closed* when the residual is in one of three certified states, and the trichotomy is the definition:

**(a) Converge.** τ-iteration drives error to zero with an explicit modulus of convergence — which is precisely constructive analysis's notion of existence (a Bishop real *is* an approximation algorithm plus modulus; the classical exact solution is recovered as this case). The engine here is the defect-equation recursion: the error of an approximant satisfies its own equation with the residual as source, so refinement is solve → form defect equation → solve that → recurse — Newton–Kantorovich structure, whose theorem supplies exactly the certified contraction the type demands, from computable quantities. Theory provides the contraction certificates; computation runs the tower; Curry–Howard makes them one object.

**(b) Promote.** Refinement stalls at an irreducible residual — and the residual becomes the *constant of integration made flesh*: promoted to a named basis element with a characterizing theorem, extending the basis, restoring closure one level up. This is not a novelty but the mechanism by which mathematics has always grown its function library: erf is literally a promoted residual named "the error function"; the Painlevé transcendents, elliptic integrals, and Bessel functions all entered as stubborn remainders that recurred until named. Physics ran the same move at its deepest level twice: the **running coupling** is an integration constant that became a function of scale satisfying its own (beta-function) equation — the c-term with dynamics; and **resurgence/trans-series** theory shows that a divergent perturbation series' error *encodes new functions* — the large-order behavior of the "failed" series determines the exponentially small non-perturbative sectors (instantons), and the Borel-summation ambiguity (the c, precisely) is fixed by the promoted content. The error term as a theorem-carrying function is established mathematical physics; the calculus makes promotion a certified operation. And the *decision* to promote is Atlas-driven and corpus-grounded per §7: when skeleton-matching detects the same residual shape recurring across many envelopes — the historical signature of every special function — that recurrence is the machine-generated promotion candidate. The basis itself lives in the discovered stratum.

**(c) Obstruct.** A certificate that no closure exists in the current basis under stated resources — and here the precedent is fully rigorous already: Liouville theory and the Risch algorithm *decide* elementary integrability, differential Galois theory proves non-existence of closed forms in a basis. Closure no-gos are not despair; they are the theorems that route the trichotomy — an obstruction certificate is exactly the license to promote.

The redefinition, then: a solution is closed when its residual is certified-converging, certified-promoted, or certified-obstructed — when *what we don't know is exactly characterized*, closure having moved up one level from the value to the error. Classical closed form is recovered as the degenerate special case where the basis is frozen at the elementary functions and only outcome (a) with error ≡ 0 counts — a freeze that was always historically arbitrary, as erf's existence attests. The higher-order math the calculus offers is this: expressions whose leaves are theorem-carrying refinement processes, precision as a resource that accumulates under iteration with certificates, and a function basis that grows by oath-bound promotion — computation and theory not integrated as neighbors but identified, term by term, as the same object read twice.

### 8.1 The double-direction method: adjoin, then resolve

The trichotomy's operational upgrade — closure worked from both ends.

**Forward: symbolic adjunction.** Do not wait for the residual to appear; *adjoin it at the start* as an opaque basis element carrying only certified interface data — its defect/annihilator equation, bounds, symmetries, asymptotics — and compute generically over it. This is Constructor 5 (adjoin-a-root) aimed at the error, and in FH it is literally the trait machinery: `var R: Residual where R: Annihilated<L> + Bounded<...>` — program against the *interface* of the unknown. The mature computational home is the holonomic/D-finite ecosystem: represent a function not by a formula but by the equation that annihilates it (erf's whole identity is erf′ = (2/√π)e^(−x²) plus a value — everything else is derived), and compute sums, products, and integrals directly on annihilators. Every downstream result is then a theorem *parametric in R*, and the forward pass yields a dividend for free: bound-minimization applied to the residual reveals **the minimal interface of the error the answer actually consumes** — frequently the observable depends on R only through a moment, a sign, or an asymptotic order, in which case no decomposition is needed at all: the answer factors through a finite spec of the unknown, and physics' beloved sum rules are exactly this phenomenon, now machine-detected.

**Backward: `atlas resolve R`.** When the interface isn't enough, resolve the residual into the terms that create it — four certified sub-operations, tried in order. *(i) Recognition:* factor the annihilator (Ore-algebra factorization; Kovacic and Risch as the decision-procedure ancestors; corpus skeleton-match against the known basis) — is R a known function in disguise? *(ii) Attribution:* the dual-weighted-residual method from numerical analysis, which is the literal existing technology for "which terms create the error" — error(observable) = Σ local residuals × adjoint weights, each contribution traced to its source; in dynamics, Mori–Zwanzig names the sources (each discarded mode's contribution to the memory kernel), so the decomposition speaks physics. *(iii) Singularity spectrum:* where divergent series are involved, Écalle's alien calculus decomposes the resurgent residual into its Borel-plane singularity content — each sector a named generating source (the instanton-by-instanton unpacking of the error). *(iv) Irreducibility:* if all three fail, differential-Galois-type irreducibility is itself a certificate — and here the double-direction method upgrades §8(b): **promotion is no longer a stall response but the residue of a certified failed resolution**, and the resolution attempt *is* the promoted function's characterizing pedigree. Newly named basis elements enter not as surrenders but as proven-irreducible atoms, with the record of everything they are not.

The loop closed: adjoin the error early, consume only its interface, resolve it late — and the calculus learns, per problem, whether the unknown dissolves (recognized), distributes (attributed), refines into named sectors (resurged), or earns its name (promoted-with-certificate). Erf run through this machine lands in state (iv) with its annihilator as pedigree — which is to say, the method's fixed point on its own founding example is precisely the historical outcome, arrived at with proofs.

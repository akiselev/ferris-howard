## 1. Tier 1 S1.2 — wallpaper/space group census "lacks a complete machine-checked treatment" — **VERDICT: NOVELTY STANDS**

No machine-checked classification of the 17 wallpaper groups, the 230 space groups, the Bieberbach theorems, or even the crystallographic restriction theorem was found in any proof assistant.

- **Coq/Rocq, Mizar, HOL Light, HoTT libraries:** nothing found in any pass.
- **Adjacent, non-machine-checked prior art (must be cited, and is an asset):** the CARAT package (Opgenorth–Plesken–Schulz, https://lbfm-rwth.github.io/carat/) computationally enumerates crystallographic groups up to dimension 6 (222,018 space groups in d=5; 28,927,915 in d=6 per Plesken–Schulz, *Experimental Math.* 2000, https://projecteuclid.org/journals/experimental-mathematics/volume-9/issue-3/Counting-crystallographic-groups-in-low-dimensions/em/1045604675.pdf), and GAP's cryst-family packages ship the tables. ## 2. Tier 1 S1.3 / Tier 2 S2.1 — certified band structures and certified invariants — **VERDICT: PARTIAL (novelty falls as worded; kernel-checked lane clear)**

The S1.3 slogan "computed everywhere and certified nowhere" is **false as written** and must be amended; the kernel-checked deliverable underneath it survives.

- **Validated-numerics band structures exist.** Herbst–Levitt–Cancès, "A posteriori error estimation for the non-self-consistent Kohn–Sham equations", *Faraday Discussions* 2020 — silicon band structure diagrams "annotated with fully-guaranteed error bars" covering discretization, iteration, *and floating-point arithmetic*. https://pubs.rsc.org/en/content/articlelanding/2020/fd/d0fd00048e · https://arxiv.org/abs/2004.13549 · code: https://github.com/mfherbst/error-estimates-nonscf-kohn-sham. The line continues: "Fully guaranteed and computable error bounds on the energy for periodic Kohn–Sham equations with convex density functionals" (https://arxiv.org/abs/2409.11769) and the DFTK publications page (https://docs.dftk.org). This is plane-wave DFT rather than tight-binding, and paper-plus-code rather than kernel-checked — but it is exactly "certified band structures" in the validated-numerics genre.
- **Rigorous finite-data topological invariants exist on paper.** The spectral localizer (Loring; Loring–Schulz-Baldes, "Finite volume calculation of K-theory invariants", *NY J. Math.* 2017, https://arxiv.org/abs/1701.07455; even pairings https://arxiv.org/abs/1802.04517; recent quantitative refinements https://arxiv.org/abs/2512.21843, https://arxiv.org/html/2506.14174) computes the K-theory index as the signature of an explicit finite matrix, **with proven explicit gap/size sufficiency bounds**. This is prior art *in kind* for S2.1's "mesh-sufficiency theorem": the folklore "finite data suffices, and here is the explicit bound" object already exists, rigorously, for the localizer route (and earlier for the Bott index, Hastings–Loring). S2.1's claim of "the tier's first genuinely new mathematical object" must be narrowed to: an explicit mesh bound *for the Fukui–Hatsugai–Suzuki discretized Berry-curvature sum specifically, tied to a certified spectral gap* — which two search passes did not find (FHS's own "admissibility" criterion is stated, not made quantitative against the gap in anything located), plus its machine-checking, which nothing touches.
- **Proof-assistant side is empty.** No formalized Bloch theorem, Berry phase, Chern number, or SSH model found in any prover; Loogle: `"Chern"` → 2 hits, both `Lean.Meta` matcher false positives; `"Berry"`, `"BlochTheorem"` → 0. **Usable infrastructure exists:** winding numbers via Cauchy indices are formalized in Isabelle/HOL (Li–Paulson, AFP `Winding_Number_Eval`, https://arxiv.org/abs/1804.03922) — relevant to the SSH winding number; interval arithmetic in Lean 4 exists (https://github.com/girving/interval; also https://github.com/alerad/leancert); and TNLean (Lu–Tjoa–Cirac, "Multi-agent Autoformalization of Tensor Network Theory", https://arxiv.org/abs/2607.07857, July 2026) autoformalized the fundamental theorem of matrix-product states in Lean 4 with extensions toward 1D symmetry-protected topological phases — the nearest Lean-side neighbor to Tier 2, on the interacting/MPS side.

**Queries run:** "Fukui Hatsugai Suzuki Chern number rigorous error bound interval arithmetic" / "verified computation topological invariants Chern number validated numerics certificate" / "Fukui-Hatsugai-Suzuki convergence proof mathematical rigorous \"admissibility\" discrete Chern number equals continuum" / "formalized Bloch theorem proof assistant Lean Isabelle" / "SSH model OR \"Su-Schrieffer-Heeger\" formalization Lean theorem prover" / "\"Berry phase\" formalization proof assistant Lean Coq formalized quantum geometric phase" / "Herbst Levitt Cancès guaranteed error bounds band structure Kohn-Sham a posteriori silicon" / "\"spectral localizer\" Loring Schulz-Baldes error bound finite volume index theorem rigorous" / "girving interval Lean 4 rigorous interval arithmetic library verified numerics" / "formalization \"topological phases\" OR \"quantum Hall\" OR \"TKNN\" proof assistant machine-checked theorem prover".

**Meaning for the tiers: REFRAME, then clear.** S1.3 must be rewritten from "certified nowhere" to "certified only in validated-numerics form (guaranteed error bars, HLC 2020), never kernel-checked — we move the certificate into the proof kernel"; S2.1's mesh-sufficiency theorem must be positioned against the spectral localizer's explicit finite-volume bounds (novel *for FHS*, and novel as a machine-checked object; not novel as "first explicit finite-data sufficiency bound for a topological invariant"). Both amendments are to prose and framing; the deliverables themselves remain unclaimed territory.

## 3. Tier 1 S1.4 — 1D Ising / transfer matrix / Onsager, formalized — **VERDICT: NOVELTY STANDS (with mandatory citations)**

No formalization of the 1D Ising transfer-matrix solution (free energy, correlation length, absence-of-transition), nor of anything Onsager, was found in any prover. But formalized statistical mechanics **does** exist and the writeup must cite it:

- **physlib itself:** `Physlib/StatisticalMechanics/` contains `CanonicalEnsemble/` (Basic, Finite, Lemmas, TwoState), `MicroCanonicalEnsemble/`, `BoltzmannConstant.lean` (verified via GitHub API listing, 2026-08-06). The canonical-ensemble two-state system is the substrate S1.4 builds on, in the same library.
- **Closest existing artifact:** Cipollina–Karatarakis–Wiedijk, "Formalized Hopfield Networks and Boltzmann Machines" (Lean 4, Dec 2025, https://arxiv.org/abs/2512.07766) — Ising-type energy functions with stochastic dynamics, convergence to a unique stationary distribution via a new Perron–Frobenius formalization. That is Glauber-dynamics-adjacent stat mech in Lean; it is not the transfer-matrix free-energy pipeline, and it does not state or prove anything about phase transitions.
- **Genre precedent:** the Josephson-lab line ("Formalizing Chemical Physics using the Lean Theorem Prover", https://arxiv.org/abs/2210.12150) for thermodynamics-in-Lean framing.
- **AFP:** no Ising/Gibbs/statistical-mechanics entries (physics topic = quantum information only). **Onsager:** nothing machine-checked anywhere; the Zeilberger–Kauers "experimental mathematics rederivation" (https://sites.math.rutgers.edu/~zeilberg/mamarim/mamarimhtml/onsager.html) is symbolic computation, explicitly non-rigorous, not a verification. Loogle: `"Ising"` → 9 hits, all `piSingle` substring false positives; `"TransferMatrix"` → 0.

**Queries run:** "Isabelle AFP Ising model transfer matrix statistical mechanics formalization" / "site:isa-afp.org Ising OR Gibbs OR \"statistical mechanics\"" / "Ising model formalization Lean 4 statistical mechanics partition function" / "Lean formalization canonical ensemble OR \"Boltzmann distribution\" OR \"two-state system\" statistical mechanics PhysLean OR Josephson" / "Curie-Weiss OR \"mean-field Ising\" formalization Lean OR Isabelle OR Coq proof assistant" / "Onsager solution two-dimensional Ising model formal proof verification computer-checked" — all negative for the deliverable itself.

**Meaning for the tier: CLEAR.** The end-to-end 1D solution appears unformalized anywhere; the tier's framing should present it as "first formalized exactly-solved statistical-mechanics model" only with the Boltzmann-machine and physlib-ensemble citations in the same breath, since "first formalized statistical mechanics" simpliciter would be false.

## 5. physlib's solid-state content ("physlib already contains the tight-binding model") — **VERDICT: CONFIRMED**

Verified at source level, 2026-08-06. The library is `leanprover-community/physlib` (formerly `HEPLean/PhysLean` — the old GitHub path redirects). `Physlib/CondensedMatter/TightBindingChain/Basic.lean` (author Joseph Tooby-Smith) contains: `TightBindingChain` (parameters), `localizedState` (orthonormal basis, orthonormality proven), the `|m⟩⟨n|` operator API, `hamiltonian` (hermiticity proven), `BrillouinZone`, `QuantaWaveNumber` (membership in BZ proven), `energyEigenstate`, `energyEigenvalue`, and `hamiltonian_energyEigenstate` — i.e., a complete finite-N diagonalization of the 1D chain with periodic boundary conditions. https://github.com/leanprover-community/physlib/blob/master/Physlib/CondensedMatter/TightBindingChain/Basic.lean

**Scope caveat for S1.1's bridge plan:** `CondensedMatter/` holds exactly `Basic.lean`, `TightBindingChain/`, and `Thermoelectric/`. One-dimensional, single-band, nearest-neighbor only — no SSH (two-band), no honeycomb/graphene, no phonons, no spin models. The foothold is real; it is one file and one model, so the S1.1 "bridge to physlib's existing formalization" is a genuine but narrow interface, and the finite-N Bloch-type diagonalization S1.1 plans partially exists for this one model already (cite it, don't rebuild it).
